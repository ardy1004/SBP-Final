Moved from CLAUDE.md (check 4, /doctor). The actual gate ORDER/sequence stays in root CLAUDE.md under "Gate sebelum deploy" since other docs in this repo reference it there by name.

- `check:turnstile` (`scripts/check-turnstile-callers.mjs`) memastikan **setiap pemanggil endpoint fail-closed mengirim `cf_turnstile_token`**. Daftar endpointnya diturunkan dari file `functions/api/**` yang memanggil `verifyTurnstile()`, jadi endpoint baru otomatis terjaga. Menyapu **dua** bentuk panggilan sekaligus — `fetch('/api/…')` mentah dan helper `api.ts` (`postLead`) — karena menyapu satu bentuk saja persis yang membuat `ContactPage.tsx` terlewat pada 29 Agu. ⚠️ Memeriksa **per TITIK PANGGIL, bukan per file** (diperketat 2026-08-30): pemeriksaan lama `isi.includes('cf_turnstile_token')` sekali per file akan LOLOS pada file yang punya dua jalur kirim dan hanya satu bertoken — bentuk kegagalan yang sama persis dengan insiden 49 hari itu. Sekarang jumlah penyebutan token harus mengimbangi jumlah titik panggil, dan komentar dibuang lebih dulu supaya komentar yang menyebut `postLead(` tidak dihitung sebagai pemanggilan. Mode `--cached` mengukur pengalaman pengguna nyata; mode default mengukur skenario terburuk tanpa cache. **Laporkan keduanya — satu angka saja menyesatkan.**
- ⚠️ **Smoke selalu hanya menyentuh SATU colo (CGK)** — scriptnya sendiri memperingatkan "cakupan geografis lemah". Angka 0/320 sahih untuk Jakarta, **bukan bukti global**. Jangan menyajikannya sebagai jaminan menyeluruh.
- **`BUDGET_FUNCTIONS_RAW` dinaikkan 6.150.000 → 6.200.000 (2026-09-02, disetujui user); terpakai 6.158.888 B = 99,3%, sisa ~41 KB.** Alasan menaikkan, bukan sekadar menyerah pada ratchet: yang dijaga angka MENTAH ini sebenarnya CPU startup — dan sejak Workers Paid batas CPU naik 10 ms → 30 detik; batas platform yang SESUNGGUHNYA diukur pada gzip (**1,29 MB dari 10 MB = 13%**); dan **Assertion A (permukaan eager) tidak disentuh, tetap 8 paket** — itulah penjaga startup yang sebenarnya. Ratchet tetap berlaku untuk pertumbuhan berikutnya: **pangkas kode dulu**, menaikkan angka tetap keputusan user. Catatan berguna: dedup lintas backend↔frontend itu murah — `inAppBrowser.js` +183 B, `metaEvents.js` mendekati nol, karena keduanya MENGGANTIKAN definisi duplikat. Fitur berikutnya hampir pasti menabraknya, dan **menaikkan angkanya keputusan user** — bukan pelanggaran teknis, karena sejak Workers Paid ini anggaran yang kita tetapkan sendiri. Sejak akun di Workers Paid, angka mentah Functions ini **anggaran yang kita tetapkan sendiri, BUKAN batas platform** — jadi menaikkannya adalah keputusan produk (tanya user), bukan pelanggaran teknis. Aturan lama tetap berlaku sebagai default: **pangkas kode dulu, jangan refleks menaikkan angka.**
- ⚠️ **Gate otomatis TIDAK menangkap bug perilaku.** Sepanjang sesi 2026-08-01/02, SEMUA bug nyata (422 talking-head, layar putih kontrak `parts`/`scenes`, arketipe tidak dipatuhi, tongsis dobel, dialog ditolak kebijakan) lolos typecheck + bundle + smoke, dan hanya ketahuan saat user benar-benar memakainya. Perlakukan uji fungsional user sebagai bagian wajib dari "selesai", bukan pelengkap.
- ⚠️ **`check:viralframe-rules` SUDAH DIHAPUS 2026-09-04** bersama tiga jalur prompt paralel yang dijaganya (`masterPromptCompiler.ts`, `ai-generate.js`, `youtube-long.js`). Jangan menambahkannya ke gate — script-nya tidak ada. Penggantinya bukan guard baru melainkan ARSITEKTUR: sekarang cuma ada SATU renderer (`renderPromptFlow()`), jadi tidak ada duplikasi yang bisa drift. **Kalau suatu saat muncul jalur prompt KEDUA** (mis. mode faceless), guard semacam itu wajib dihidupkan lagi bersamaan — drift lintas jalur tidak pernah tertangkap typecheck karena backend JS tidak punya typecheck.
